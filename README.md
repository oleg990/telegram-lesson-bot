# Бот-воронка: инструкция

## Что менять под себя (для вас или для покупателя)
1. `.env` — токен бота (из @BotFather), ваш Telegram id, канал и ссылка на канал.
2. `settings.json` — тексты приветствия, названия кнопок и уроки.

Код (`bot.py`) трогать не нужно. Чтобы передать бота другому человеку: он создаёт своего бота в @BotFather, меняет четыре строки в `.env`, правит `settings.json` и запускает на своём хостинге.
База пользователей (`users.db`) при передаче НЕ отдаётся: это личные данные ваших подписчиц.

## Панель управления (только с вашего аккаунта)
Напишите боту /admin: появится меню с кнопками.
- 📊 Статистика
- 📣 Сделать рассылку: нажимаете, присылаете текст/фото/видео (ссылки можно вставлять в текст), бот показывает, как выглядит, и спрашивает подтверждение
- 📥 Скачать базу таблицей
- 🔗 Ссылки на бота (в том числе с метками)

## Метки источника
Ссылка вида `https://t.me/ИМЯ_БОТА?start=insta` запомнит, что человек пришёл из Instagram.

## Запуск
pip install -r requirements.txt
python bot.py

Важно: бот должен быть администратором вашего канала, иначе он не сможет проверять подписку.

## Рассылка (обновлено)
В /admin → «Сделать рассылку»: сообщение → кому (все / не взяли доступ / взяли доступ / новые за 7 дней / по метке) → кнопка-ссылка (по желанию) → сейчас или по расписанию → предпросмотр и подтверждение. Запланированные видны и отменяются в «📅 Запланированные рассылки». После отправки бот присылает отчёт: доставлено / не дошло.
Часовой пояс расписания по умолчанию Europe/Moscow; поменять: строка TZ_NAME=Europe/Kyiv в .env.
Обновление работающего бота: заменить bot.py, выполнить `/opt/tgbot/venv/bin/pip install tzdata`, затем `systemctl restart tgbot`. База не теряется.
